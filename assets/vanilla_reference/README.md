# Vanilla Pokémon Emerald pieces

Cut from base-game art (also in this codebase's own tilesets), read from a ROM for convenience.

- `ice_boulder.png`: Shoal Cave's ice boulder (the low-tide ice room, cell (6,2)), cut against its ice floor with the
  floor's own colours dropped. Used by the ice path under Pelluca's church (`tools/art/icepath/`).
