# Pokémon Rejuvenation tilesets (credit: the Pokémon Rejuvenation team)

Supplied by the user (2026-11-19), from friends on the Rejuvenation team, for the Templar Monastery hall.

- `ArceusRuins.png`: 256 px wide RPG Maker XP sheet. The art is pixel-doubled, so it halves exactly to GBA scale.
- `Church.jpg`: arrived as a resized JPEG (222 px wide), not the original PNG. Its stained glass is
  resampled to GBA scale and quantized by `tools/art/templar/compose_mock.py`. If the original PNG turns up,
  drop it in here and the windows can be rebuilt pixel-exact.

Used by `tools/art/templar/` (mock and `build_hall.py`). Credit the Rejuvenation team alongside MonoMyth and
Pokémon Odyssey.
