# Pelluca Tileset Source (Evernahn) — RMXP source, NOT yet converted

RMXP-format source tileset assets for the **Pelluca Valley** map build (bible §16.3 / §18).
These are the original 32px RMXP tiles — they must be **converted to pokeemerald format**
(32px→16px metatiles + palette fit + primary/secondary split) before any map can use them.
See bible §18 "Evernahn tileset conversion" for the process and the metatile-budget constraint.

- `Evernahn.png` — main tileset
- `Evernahn_Grass_1/2/3.png` — grass autotiles
- `Evernahn_Water.png`, `Evernahn_Water_2.png` — water autotiles
- `Calvera_Water.png`, `Calvera_Water_Calm.png` — water tiles
- `Map005.rxdata`, `Map588.rxdata` — RMXP map data (Evernahn/DM reference maps)
- `Tilesets.rxdata` — RMXP tileset definitions
